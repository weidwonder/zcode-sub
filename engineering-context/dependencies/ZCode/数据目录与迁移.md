# 业务域卡 — ZCode › 数据目录与迁移

## 职责

用户数据在磁盘上的布局（`~/.zcode`）、三个 SQLite 库的迁移账本机制、跨版本打开（升级/降级）的兼容行为。

## 陷阱项

- 文件复制备份会话库 — 库可达 1 GB 且 WAL 活跃，复制会撕裂；备份必须用 sqlite3 在线备份（`.backup`）。
- 降级使用期间的写回 — 旧版保存设置会抹掉新版新增设置键；消息行被旧版写回会丢新增字段（渐进损耗，不炸）。
- 上游改已应用迁移的 SQL — 才是降级真正的炸点（`MigrationChecksumError` 阻断启动）；上游自称冻结这些 SQL，改前用本仓 `patch/verify-migration-checksums.mjs` 门检。
