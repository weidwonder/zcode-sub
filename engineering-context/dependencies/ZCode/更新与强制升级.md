# 业务域卡 — ZCode › 更新与强制升级

## 职责

打包版的两道版本门（自动更新器与启动期强制升级检查），决定「旧版本客户端能不能继续连生产后端」。

## 陷阱项

- `ZCODE_AUTO_UPDATE=0` — 关不掉强更门；两道门独立，强更门只看 flavor + isPackaged，不看构建期自动更新开关。
- 把补丁版版本号伪标成已装正式版号 — 服务端按 `app_version` 参数下发配置与灰度（请求见 forceUpdateGuard），旧代码持续领新版服务端行为，错配面不可枚举；不可取。
